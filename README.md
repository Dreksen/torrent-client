# BitTorrent Client на C++

Учебный проект на **C++20**, посвящённый устройству протокола BitTorrent и базовым принципам peer-to-peer загрузки. В проекте реализованы парсинг `.torrent`-файлов, запрос списка пиров у трекера, TCP-соединение с пиром и отдельные компоненты для представления протокольных сообщений и частей файла.

> **Статус проекта:** прототип находится в разработке. Основной цикл обмена данными с пиром (`PeerConnect::MainLoop`) пока является заглушкой, а запись скачанных данных в файл не реализована. Поэтому текущая версия ещё не является полноценным BitTorrent-клиентом и не гарантирует загрузку файла целиком.

## Возможности

- Собственный парсер **Bencode** для целых чисел, строк, списков и словарей.
- Чтение метаданных `.torrent`: имени, размера, длины части файла, хешей частей и адреса трекера.
- Вычисление `info hash` по исходному Bencode-представлению секции `info`.
- HTTP-запрос к трекеру и разбор компактного списка IPv4-пиров.
- Работа с TCP-сокетами: подключение с тайм-аутом, отправка и чтение заданного количества байтов.
- Формирование и разбор сообщений BitTorrent.
- Реализация handshake и начального обмена данными с пиром.
- Представление доступности частей через bitfield.
- Модели `Piece` и `PieceStorage` для учёта блоков размером до 16 KiB, их состояния и проверки SHA-1-хеша полученной части.

## Стек технологий

- **C++20**
- **CMake** — сборка проекта
- **OpenSSL** — вычисление SHA-1
- **CPR / libcurl** — HTTP-запросы к трекеру
- POSIX sockets — TCP-соединения 

## Структура проекта

| Файл или компонент | Назначение |
|---|---|
| `bencode.*` | Разбор данных в формате Bencode |
| `torrent_file.*` | Чтение метаданных `.torrent` и вычисление `info hash` |
| `torrent_tracker.*` | Запрос списка пиров у трекера |
| `tcp_connect.*` | Низкоуровневая работа с TCP-сокетом, тайм-ауты и чтение/отправка данных |
| `peer_connect.*` | Соединение с пиром, handshake и начальный обмен сообщениями |
| `message.*` | Представление, сериализация и разбор сообщений протокола |
| `byte_tools.*` | Преобразование big-endian значений и вычисление SHA-1 |
| `piece.*` | Блоки одной части файла, сборка данных и проверка хеша |
| `piece_storage.*` | Учёт частей файла, ожидающих обработки |
| `resources/` | Пример `.torrent`-файла для запуска |

## Требования

- CMake версии 3.16 или новее;
- C++-компилятор с поддержкой C++20;
- OpenSSL;
- libcurl и инструменты сборки (`make` и компилятор).

### Установка зависимостей в Ubuntu / Debian

```bash
sudo apt update
sudo apt install -y build-essential cmake libcurl4-openssl-dev libssl-dev
```

При первой конфигурации CMake загружает CPR через `FetchContent`, поэтому для первоначальной сборки также понадобится доступ к GitHub.

## Сборка

Из корневой директории проекта выполните:

```bash
cmake -S . -B build
cmake --build build -j
```

CMake-конфигурация проекта включает AddressSanitizer.

## Запуск

```bash
./build/download-pieces
```

Программа перебирает файлы в директории `resources/`, пытается прочитать метаданные торрента, обратиться к трекеру и подключиться к найденным пирам. Запускайте её из корневой директории проекта, поскольку путь к `resources/` задаётся относительно текущей рабочей директории.

Для сетевой части нужны доступ к интернету и доступный трекер/пиры. Поведение запуска зависит от доступности этих узлов. Из-за незавершённого `MainLoop` и проверочных `assert` программа может завершиться ошибкой; полноценная загрузка файла на диск пока не поддерживается.
